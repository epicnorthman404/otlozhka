# Отложка

**Ваши деньги. Ваш браузер. Ни сервера, ни аккаунта.**

Отложка — личный трекер месячного бюджета: цели и факт по доходам,
расходам и сбережениям, норма сбережений, структура трат и история по
месяцам. Это один HTML-файл: открывается прямо в браузере, все данные
остаются на вашем устройстве — ничего никуда не отправляется.

## Особенности

- **Без сервера и без базы данных.** Один файл — откройте двойным кликом,
  выложите на свой хостинг или на GitHub Pages.
- **Данные только у вас.** Всё хранится в `localStorage` браузера: ни
  аналитики, ни трекеров, ничего не уходит на сторону.
- Цель / факт по доходам и постоянным расходам, отдельно — просто факт по
  переменным тратам (их не угадаешь заранее)
- Норма сбережений — круговой индикатор с ориентиром
- Диаграмма структуры расходов по категориям
- История по месяцам — график доходов / расходов / сбережений в динамике
- Резервная копия одной кнопкой — выгрузка/загрузка всех месяцев в JSON-файл
- Светлая и тёмная тема, переключается вручную
- Адаптивная вёрстка — одинаково удобно на телефоне, планшете и компьютере

## Быстрый старт

### Вариант 1 — просто открыть файл

Скачайте [`index.html`](index.html) и откройте в браузере. Работает офлайн,
ставить ничего не нужно.

### Вариант 2 — Docker (для своего сервера)

```bash
docker run -d --name otlozhka -p 8080:80 ghcr.io/ВАШ_GITHUB_ЛОГИН/otlozhka:latest
```

Откройте `http://localhost:8080` (или `http://IP_СЕРВЕРА:8080`).

Либо через `docker-compose.yml`:

```bash
docker compose up -d
```

### Вариант 3 — любой статический хостинг

Это просто HTML-файл — подойдёт GitHub Pages, Netlify, Vercel, свой nginx
или Caddy — что угодно, что умеет отдавать статику. Никакого бэкенда,
никакой сборки.

## Где хранятся данные?

В `localStorage` вашего браузера, на вашем устройстве. Между разными
браузерами и устройствами данные **не синхронизируются** — это осознанный
компромисс в пользу простоты и приватности: нет сервера — нечему течь и
нечего ломать.

Важно понимать, что стирает эти данные: очистка **истории посещений**
их не трогает, а вот очистка **«куки и данные сайтов»** (или «очистить
всё») сотрёт их безвозвратно — так же, как переустановка браузера, сброс
устройства или смена браузера на другой.

Чтобы подстраховаться — в шапке приложения есть кнопки ⬇ (скачать резервную
копию всех месяцев в JSON-файл) и ⬆ (загрузить копию обратно, в том числе на
другом устройстве или в другом браузере).

Нужна настоящая синхронизация между устройствами в реальном времени или
общий доступ для семьи — потребуется уже бэкенд с аккаунтами; это отдельная,
более сложная версия проекта.

## FAQ

**Это бесплатно?**
Да. MIT-лицензия — код открыт, делайте с ним что хотите.

**Нужен ли сервер?**
Нет. Файл можно открыть прямо с диска.

**Можно с телефона?**
Да — откройте в браузере и добавьте на главный экран, будет вести себя как
приложение.

**Несколько человек?**
У каждого — свои локальные данные в своём браузере. Аккаунт не нужен: если
двое открывают одну и ту же ссылку с разных устройств, это два независимых
набора данных.

**Как перенести данные на новое устройство?**
Кнопка ⬇ в шапке — скачать резервную копию (JSON), кнопка ⬆ на новом
устройстве/браузере — загрузить её обратно.

## Технические детали

- Чистые HTML / CSS / JS, без сборки и внешних зависимостей.
- Хранение — Web Storage API (`localStorage`).
- Графики (диаграмма расходов, история по месяцам) — inline SVG, без
  сторонних библиотек.
- Шрифты подключаются с Google Fonts; при недоступности используется
  системный шрифтовой стек.
